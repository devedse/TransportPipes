# Playing together: the design record

The working notes behind `docs/multiplayer-design.html`: six design agents with one point of view each (the idea
thrower, the friends-first designer, the guardian of lonely players and leavers, the economy and long-game designer,
the psychologist and game historian, and an outsider without any context), in five rounds.

| Files | Round |
| --- | --- |
| `brief.md` | The checklist every idea is scored against, written before the brainstorm |
| `1-wild.md` … `6-outsider.md` | Round 1: each agent alone, as wild as possible |
| `r2-*.md` | Round 2: everyone read everyone, attacked, stole and played six hard cases |
| `round3.md` | The three rival concepts, the twelve questions to decide and the hard cases a–h |
| `r3-A.md`, `r3-B.md`, `r3-C.md` · `r3-exam-*.md` | Round 3: the champions' full specs and the examiners' tests |
| `r4-exam-*.md` · `r4-defense-*.md` | Round 4: the verdicts and the champions' defences |
| `r5-review-*.md` | Round 5: the final review of the first draft (economy, lonely, outsider and a cold read) |

The HTML is the decision; these files are how it was reached. Where they disagree with it, the HTML wins.
