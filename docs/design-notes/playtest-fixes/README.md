# Fixing what the first AI playtest found: the record

The working notes behind `docs/playtest-fixes.html`: five agents, each with one point of view (the systems engineer,
the economy designer, the clarity and onboarding designer, the cooperation designer and the player researcher), in
three rounds, on the outcome of the AI playtest `story1` (`playtest/runs/story1/`).

| Files | Round |
| --- | --- |
| `brief.md`, `roles.md` | The brief and the roles, written before round 1 |
| `r1-*.md` | Round 1: each alone, from their seat |
| `r2-*.md` | Round 2: everyone read everyone, agreed, objected, ranked |
| `plan-draft.md` · `r3-*.md` | Round 3: the moderator's draft plan, and each role's verdict on it |

The HTML is the decision; these files are how it was reached. Where they disagree with it, the HTML wins.
